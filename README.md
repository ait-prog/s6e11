# Kaggle Playground S6E11 — Predicting Credit Card Fraud

Метрика ROC AUC. Фолды для всех моделей: `StratifiedKFold(5, shuffle=True, random_state=42)`.

## Структура

| путь | что |
|---|---|
| `src/lm.py` | target-first языковая модель (Bayes по двум меткам) и режим `any` (метка в случайном месте, чтение с метки последней); токенизации `dig` / `l3` / `bpe`, полу-обучение на неразмеченных строках |
| `src/stk.py` | широкий стек: банки OOF, дедупликация, логистический стекер (свой Newton float32), nested CV |
| `src/mk.py` | генерация и пуш Kaggle-прогонов `s6e11-devN`, скачивание выходов |
| `k/devN/` | код и метаданные каждого прогона на Kaggle |
| `out/devN/` | логи и метаданные выходов (сами банки предсказаний не в git) |
| `sub/` | сабмиты, nested OOF и коэффициенты стека |
| `ref/` | публичные ноутбуки соревнования, разобранные при подготовке |
